# Sources: science/pki

THROWAWAY TEST FIXTURES. Every key here was generated for these tests only,
protects nothing and must never be used for anything else. Subjects are
`CN=test.example` / `CN=ca.test.example` (`O=Test Fixtures`, `C=XX`); IP
addresses come from the documentation range 192.0.2.0/24. SSH keys carry an
empty comment (`ssh-keygen -C ""`, checked: no user or host name). Generated by
`gen_pki.sh` (OpenSSL 4.1.0, OpenSSH `ssh-keygen` of macOS, Python 3 venv with
cryptography 50.0.2, jwcrypto and PyJWT 2.15.1) and, for OpenPGP, GnuPG 2.4.4
in a throwaway Ubuntu 24.04 container. Commands run in this directory.

Interop of Convertible's output (checked by the tests themselves): DER, PEM and
PKCS#7 written by Convertible are byte-identical to OpenSSL's files; SPKI PEM
made from OpenSSH keys equals ssh-keygen/cryptography output and converts back
to the identical OpenSSH line; JWKs made from PEM have the same kty/crv/x/y as
jwcrypto's; the binary OpenPGP key made from the armour equals GnuPG's export.
