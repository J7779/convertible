# Changes to Speex 1.2.1

- Only the codec sources of `libspeex` listed in its `Makefile.am` and the
  public headers are kept (no tools, tests, documentation or build system).
- Added `include/speex/speex_config_types.h`, normally generated by
  `configure`, with the fixed-width types from `<stdint.h>`.
- Built as floating point (`FLOATING_POINT`, `USE_SMALLFT`, empty `EXPORT`);
  every global symbol gets a `cvt_` prefix through a force-included rename
  header (see `core/src/families/audio_lossy/cmake/xiph.cmake`). The source
  files themselves are unchanged.
