# Document family fixtures

All content is synthetic (lorem ipsum, made-up tables, example.com/.org/.net
addresses). Each sub-directory has a section below saying how its files
were made.

## sample/

The one synthetic source document from which most fixtures are produced, so
that every reader can be checked against the same known structure.

| File | Content | Made with |
| --- | --- | --- |
| `sample.md` | Pandoc Markdown, written by hand: title "Sample Document" (front matter), 6 headings (levels 1-3: "Lorem Ipsum Overview", "Lists and Structure", "Table Section", "Code and Quotes", "Unicode Corner" plus the title), a bullet list of 3 items with a nested list of 2, an ordered list of 3, one definition list item, a 3-column x 4-row table (header Name/Quantity/Price; left/right/center aligned), a Python code block, a block quote, Latin/Greek/CJK/Hebrew/Arabic text and emoji, one footnote, superscript/subscript, one picture, a rule, links to https://example.com/docs, https://example.org/page, https://example.net/ | text editor |
| `pixel.png` | 4x4 RGB picture, #3366cc with two #ffcc00 pixels at (1,1) and (2,2) | ImageMagick 7: `magick -size 4x4 xc:"#3366cc" -fill "#ffcc00" -draw "point 1,1 point 2,2" -strip PNG24:pixel.png` |

## pandoc/

`pandoc/core:latest`), run from this directory as

    docker run --rm -v "$PWD":/w -w /w/sample pandoc/core:latest sample.md -t <format> [-s] -o ../pandoc/<file>

Tool attributions were then removed (BSD sed):

    sed -i '' '/Automatically generated by/d' pandoc/sample.1
    sed -i '' 's#<p>Produced by pandoc.</p>#<p>Synthetic sample.</p>#' pandoc/sample.tei.xml
    sed -i '' '/name="generator"/d; /Default styles provided by/d; /See https:\/\/pandoc.org/d; /^    \*\/$/d' pandoc/sample.html
    sed -i '' 's#<document-info><program-used>pandoc</program-used></document-info>##' pandoc/sample.fb2
    sed -i '' 's#  hidelinks,#  hidelinks}#; /pdfcreator=/d' pandoc/sample.tex

## Interop of our writers

`sample/sample.md` was converted with our writers (the `convertible` CLI of
this tree) and the results read back with pandoc 3.14 (`pandoc/core` Docker
image, `pandoc ours.<ext> -f <format> -t plain`); "similarity" is Python
`difflib.SequenceMatcher` on whitespace-normalised text against
`pandoc sample.md -t plain`. Every file was accepted without warnings.

| --- | --- | --- |
| html | html | 0.995 |
| md (gfm) | gfm | 0.995 |
| rst | rst | 0.962 |
| asciidoc | asciidoc | 0.981 |
| org | org | 0.992 |
| mediawiki | mediawiki | 0.995 |
| dokuwiki | dokuwiki | 0.991 |

Further checks of the same outputs: `xmllint --noout` accepts the DocBook,
FB2 and OPML files; `mandoc -T lint` reports only style notes on the man page;
in an `ubuntu:24.04` container with TeX Live 2023 and Texinfo 7,
`pdflatex` and `xelatex` compile the LaTeX article and `makeinfo` (Info and
HTML) accepts the Texinfo file without errors.
