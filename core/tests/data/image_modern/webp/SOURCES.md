# WebP fixtures

All files are synthetic test patterns. They are regenerated by
`make_fixtures.py` (Python 3 standard library for the patterns), which runs
Google's libwebp 1.6.0 command line tools (`cwebp`, `dwebp`, `img2webp`,
`gif2webp`, `webpmux`, `anim_dump`, built from the upstream `v1.6.0` tag in a
scratch directory) and ImageMagick 7.1.2-36 (whose WebP delegate is libwebp
1.6.0). None of them was produced by Convertible.

```sh
WEBP_TOOLS=<directory with the libwebp tools> python3 make_fixtures.py
```

| File | Content | Command |
| --- | --- | --- |
| `src_rgb.ppm` | 64x48 pattern: ramps, a checker band (rows 16-23), a hard diagonal edge | Python (P6 writer) |
| `src_rgba.pam` | the same with an alpha ramp, opaque columns 0-7, fully transparent rows 40-47 with colour underneath | Python (P7 writer) |
| `lossless.webp` | VP8L of `src_rgb.ppm` | `cwebp -lossless src_rgb.ppm` |
| `lossless_alpha.webp` | VP8L with alpha, hidden colours kept | `cwebp -lossless -exact src_rgba.pam` |
| `magick_lossless_alpha.webp` | the same through ImageMagick | `magick src_rgba.pam -strip -define webp:lossless=true -define webp:exact=true` |
| `lossy.webp` | VP8 | `cwebp -q 80 src_rgb.ppm` |
| `lossy_dwebp.ppm` | reference decode of `lossy.webp` | `dwebp lossy.webp -ppm` |
| `lossy_alpha.webp` | VP8X + ALPH + VP8 | `cwebp -q 80 -alpha_q 90 src_rgba.pam` |
| `lossy_alpha_dwebp.pam` | reference decode | `dwebp lossy_alpha.webp -pam` |
| `magick_lossy.webp` | VP8 written by ImageMagick | `magick src_rgb.ppm -strip -quality 60` |
| `magick_lossy_dwebp.ppm` | reference decode | `dwebp magick_lossy.webp -ppm` |
| `photo_lossless.webp` | 96x64 shading with deterministic grain (a "lossless photo" for the compress path) | `cwebp -lossless photo.ppm` |
| `metadata.webp` | 16x8 lossless pattern + EXIF (TIFF, Orientation 6, Software "pattern") + a 132-byte header-shaped ICC blob + an XMP packet with `dc:title` "pattern" | `cwebp -lossless`, then `webpmux -set exif`, `-set icc`, `-set xmp` |
| `metadata_upright.pam` | the 16x8 pattern rotated 90 degrees clockwise (what orientation 6 displays) | `magick small.pam -rotate 90` |
| `anim_mux.webp` | 32x24, 4 lossless frames: full red canvas with a blue square (100 ms, no blend); 8x8 green at (8,4), blended, disposed to background (200 ms); 8x8 yellow alpha 128 at (16,8), blended (300 ms); 4x4 white at (2,2), not blended (400 ms); loop count 3, background colour white | `webpmux -frame f0.webp +100+0+0+0-b -frame f1.webp +200+8+4+1+b -frame f2.webp +300+16+8+0+b -frame f3.webp +400+2+2+0-b -loop 3 -bgcolor 255,255,255,255` |
| `anim_mux_0000.pam` ... `_0003.pam` | the composited canvases | `anim_dump -pam anim_mux.webp` |
| `anim_lossy.webp` | 32x24, 3 lossy frames, yellow square moving over blue, 80/120/40 ms, loop forever (the animation encoder stores sub-rectangles) | `img2webp -loop 0 -lossy -q 70 -d 80 m0.pam -d 120 m1.pam -d 40 m2.pam` |
| `anim_lossy_0000.pam` ... `_0002.pam` | the composited canvases | `anim_dump -pam anim_lossy.webp` |
| `anim_gif2webp.webp` | 24x16 red, lime, blue frames of 100/200/300 ms, loop count 2 | `magick -size 24x16 -delay 10 xc:red -delay 20 xc:lime -delay 30 xc:blue -loop 2 rgb.gif`, then `gif2webp rgb.gif` |

Every file was checked with `LC_ALL=C grep -aiE` for user names, home
directories and host names: nothing found. The EXIF block contains only the
two tags listed above.

## Interoperability of Convertible's output

Checked during development with the same libwebp 1.6.0 tools, ImageMagick
7.1.2-36 and macOS `sips` (ImageIO):

| Our file | Check | Result |
| --- | --- | --- |
| lossy still (`src_rgb.ppm` -> webp, defaults) | `webpinfo`; `dwebp -pam` vs our decoder; `sips`; ImageMagick | valid; identical pixels (AE 0) |
| lossy with alpha (`src_rgba.pam` -> webp) | `webpinfo`; `dwebp` vs our decoder; `sips -g hasAlpha` | valid; AE 0; alpha present |
| lossless with alpha, `exact` | `webpinfo`; `dwebp` vs source and vs our decoder; `sips` -> PNG | valid; AE 0 against the source |
| near-lossless 60 | `webpinfo`; `dwebp` vs our decoder | valid; AE 0 |
| lossy and lossless animation (re-encoded `anim_mux.webp`) | `webpinfo`; `webpmux -info` (frames, offsets, dispose/blend, durations 100/200/300/400, loop 3); `anim_dump` vs the fixture dumps; ImageMagick `identify`; `sips` | valid; lossless frames identical to the reference canvases |
| metadata kept (`strip_metadata=false`) | `webpinfo`; `webpmux -info` (ICC 132 B, EXIF 46 B, XMP 299 B) | valid; chunks present, pixels upright 8x16 |
