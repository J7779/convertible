# Sources: pim

The pim fixtures are grouped by area; each directory documents its own files:

- `calendar/SOURCES.md` — iCalendar, vCalendar and calendar CSV files
- `contacts/SOURCES.md` — vCard, jCard, xCard, LDIF and contacts CSV files
- `playlists/SOURCES.md` — M3U/M3U8 (incl. HLS), PLS, XSPF, ASX, WPL, iTunes XML, CUE
- `bookmarks/SOURCES.md` — Netscape bookmark HTML, browser JSON, .url, .webloc, .desktop
- `feeds/SOURCES.md` — RSS 2.0, RSS 1.0, Atom, JSON Feed
- `bibliography/SOURCES.md` — BibTeX/BibLaTeX, RIS, EndNote, CSL-JSON, MEDLINE, MODS, RefWorks, Web of Science
- `mail/SOURCES.md` — .eml, mbox, .emlx
